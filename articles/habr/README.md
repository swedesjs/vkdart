# Как написать бота для ВКонтакте на Dart с помощью VKDart

В этой статье соберём небольшого бота для сообщества ВКонтакте. Он будет отвечать на приветствие и команды, а ещё покажет клавиатуру с кнопками. Без магии, сложных фреймворков и внезапного экзамена по программированию — будем разбираться шаг за шагом 🙂

Сначала установим Dart и редактор кода, потом создадим проект и ключ доступа сообщества. После этого напишем бота, запустим и проверим его в сообщениях. Если какой-то термин пока незнаком — ничего страшного: разберёмся по дороге.

Для примера возьмём Dart и пакет [VKDart](https://pub.dev/packages/vkdart). Если вы уже пишете на Dart или Flutter, некоторые концепции будут знакомы. А если нет — этот небольшой консольный проект вполне подходит для первого знакомства.

Dart умеет ждать ответ от VK API, не останавливая при этом всю программу. Для этого есть `Future` и `Stream`. Совсем простое объяснение: `Future` ждёт один результат, а `Stream` — это поток, в котором со временем появляются новые события. Например, новые сообщения.

VKDart получает события сообщества и помогает отправлять запросы к VK API. А что именно делать с сообщением — поздороваться, показать меню или ответить «не знаю такую команду» — решаем мы сами.

Статья написана для версии пакета VKDart **2.3.3**. Все ссылки на исходники библиотеки и официальные примеры закреплены на теге `v2.3.3`. Полный код бота из этой статьи можно [скопировать из отдельного файла](https://github.com/swedests/vkdart/blob/master/articles/habr/source/bin/vk_bot.dart); [шаблон `config.dart`](https://github.com/swedests/vkdart/blob/master/articles/habr/source/config.dart) поможет подготовить настройки.

Полезные ссылки, чтобы не потерялись:

- [VKDart 2.3.3 на pub.dev](https://pub.dev/packages/vkdart/versions/2.3.3) — страница этой версии пакета;
- [документация VKDart 2.3.3](https://pub.dev/documentation/vkdart/2.3.3/) — описание классов и методов;
- [исходный код VKDart 2.3.3](https://github.com/swedests/vkdart/tree/v2.3.3) — файлы проекта в соответствующем теге;
- [примеры VKDart 2.3.3](https://github.com/swedests/vkdart/tree/v2.3.3/example) — примеры из этого релиза;
- [документация VK API](https://dev.vk.com/ru/) — официальные сведения о методах и событиях ВКонтакте;
- [установка Dart](https://dart.dev/get-dart) — официальные инструкции для разных операционных систем;

## Устанавливаем Dart и создаём проект 🛠️

Нам понадобится Dart SDK — набор инструментов, который позволяет запускать программы на Dart. Наш проект будет консольным: у него не будет отдельного окна с кнопками, он будет работать в терминале и печатать туда сообщения. Для бота этого достаточно. В статье подробно разберём Windows, а инструкции для macOS и Linux оставим чуть ниже.

### Windows

Установим Dart через `winget` — стандартный менеджер пакетов Windows. Команду нужно выполнить в PowerShell, запущенном с правами администратора:

```powershell
winget install --id Google.DartSDK --exact
```

Если вы ещё не открывали PowerShell, сделайте так:

1. Откройте меню **Пуск**.
2. Начните набирать `PowerShell`.
3. В результатах поиска нажмите правой кнопкой на **Windows PowerShell** или **Терминал** и выберите **Запуск от имени администратора**.
4. Если Windows спросит разрешение внести изменения, подтвердите запуск.
5. Скопируйте команду установки выше, вставьте её в окно PowerShell и нажмите `Enter`.
6. Если установщик попросит подтвердить действие, введите `Y` и снова нажмите `Enter`.

Дождитесь завершения установки. В конце может появиться сообщение о том, что пакет установлен. Закройте PowerShell и откройте его заново: новое окно подхватит обновлённые настройки системы.

Проверим, что `winget` и Dart доступны:

```powershell
winget --version
dart --version
```

Первая команда покажет версию менеджера пакетов, вторая — версию Dart SDK. Если `winget` не найден, откройте **Microsoft Store** и установите или обновите приложение **App Installer**. Если `dart` пока не найден, перезапустите терминал или компьютер и повторите проверку. Не переживайте, перезагрузка — не заклинание, а просто способ обновить список доступных команд Windows.

### macOS

Если вы работаете на macOS и Homebrew уже установлен, откройте Terminal и выполните:

```shell
brew tap dart-lang/dart
brew install dart
```

Если Homebrew ещё нет, инструкция по его установке есть на [официальном сайте](https://brew.sh/).

### Linux 🐧

Установка в Linux зависит от дистрибутива. Откройте [официальную инструкцию Dart](https://dart.dev/get-dart), выберите свою систему и выполните шаги именно для неё.

### Убеждаемся, что Dart установлен

После установки откройте новый терминал и выполните:

```shell
dart --version
```

Если видите номер версии, всё получилось — можно двигаться дальше. Если терминал пишет, что команда не найдена, перезапустите его. Windows иногда нужно чуть времени, чтобы познакомить новый Dart с командной строкой.

### Создаём проект

Теперь создадим папку проекта. Откройте обычный терминал (администраторские права для следующих команд уже не нужны) и перейдите в папку, где хотите хранить проект. Например, чтобы создать его на рабочем столе Windows, выполните:

```powershell
cd $HOME\Desktop
```

Если хотите сохранить проект в другом месте, укажите путь к нужной папке вместо `$HOME\Desktop`. Когда терминал окажется там, выполните:

```powershell
dart create -t console-simple vk_bot
cd vk_bot
```

Что произошло:

- `dart create -t console-simple vk_bot` создал папку `vk_bot` с простым консольным приложением;
- `cd vk_bot` переместил терминал внутрь этой папки.

Теперь добавим VKDart версии `2.3.3`:

```powershell
dart pub add vkdart:2.3.3
```

Команда добавит VKDart с ограничением версии `^2.3.3`, которое допускает совместимые выпуски в ветке 2.x, и запишет его в `pubspec.yaml` — файл со списком зависимостей проекта. Pub зафиксирует выбранную версию в `pubspec.lock`.

![Зависимость VKDart в файле pubspec.yaml](https://raw.githubusercontent.com/swedests/vkdart/master/articles/habr/images/21-pubspec-dependencies.png)

Если команда завершилась успешно, в терминале появится сообщение о добавлении пакета. Отлично, наш проект теперь умеет обращаться к VK API.

Для редактирования кода установите [Visual Studio Code](https://code.visualstudio.com/) и расширение **Dart**. Можно использовать и IntelliJ IDEA / Android Studio с плагином Dart, но далее в примерах покажем VS Code.

В VS Code:

1. Выберите меню **Файл → Открыть папку**.
2. Найдите папку `vk_bot`, созданную предыдущими командами, и откройте её.
3. Если VS Code спросит, доверяете ли вы авторам файлов в папке, подтвердите, что это ваш проект.
4. Слева появится список файлов. Пока нам важны два: `bin/vk_bot.dart` — сюда мы поместим код бота, а `pubspec.yaml` — список библиотек проекта.

## Настраиваем сообщество и токен 🔑

Бот будет обращаться к VK API с ключом доступа сообщества.

Ключ доступа подтверждает, что бот действительно управляет именно этим сообществом. Создать такой ключ можно только в компьютерной версии ВКонтакте — откройте VK в браузере на компьютере.

1. Откройте страницу сообщества, для которого хотите сделать бота. У вас должны быть права администратора этого сообщества.
2. На главной странице сообщества нажмите **Управление**.

![Главная страница сообщества: кнопка «Управление»](https://raw.githubusercontent.com/swedests/vkdart/master/articles/habr/images/03-community-page.png)

3. В меню настроек сообщества выберите **Дополнительно**, затем — **Работа с API**.

![Настройки сообщества: пункт «Дополнительно»](https://raw.githubusercontent.com/swedests/vkdart/master/articles/habr/images/04-community-management.png)

![Раздел «Работа с API»](https://raw.githubusercontent.com/swedests/vkdart/master/articles/habr/images/05-work-with-api.png)

4. Откройте вкладку **Ключи доступа** и нажмите **Создать ключ**.

![Создание ключа доступа](https://raw.githubusercontent.com/swedests/vkdart/master/articles/habr/images/06-create-access-key.png)

5. Для этого примера достаточно разрешения **Сообщения сообщества**. Если вашему боту нужны другие методы VK API, выдавайте только необходимые им права — не включайте лишнее.

![Выбор прав для ключа доступа](https://raw.githubusercontent.com/swedests/vkdart/master/articles/habr/images/07-key-permissions.png)

6. Нажмите **Создать**. VK может запросить подтверждение: откройте push-уведомление на телефоне и подтвердите создание ключа. После этого ключ появится в списке. Нажмите **Показать**, скопируйте его и храните как пароль.

![Ключ доступа создан](https://raw.githubusercontent.com/swedests/vkdart/master/articles/habr/images/08-access-key-created.png)

7. В разделе **Работа с API** откройте вкладку **Long Poll API**.

![Вкладка «Long Poll API»](https://raw.githubusercontent.com/swedests/vkdart/master/articles/habr/images/09-long-poll-tab.png)

8. На вкладке **Настройки** включите Long Poll API и выберите версию API `5.131`.

![Long Poll API включён, версия 5.131](https://raw.githubusercontent.com/swedests/vkdart/master/articles/habr/images/10-long-poll-settings.png)

9. Перейдите в **Типы событий** и включите событие **Входящее сообщение** (`message_new`).

![Вкладка «Типы событий»](https://raw.githubusercontent.com/swedests/vkdart/master/articles/habr/images/11-event-types-tab.png)

![Включено событие «Входящее сообщение»](https://raw.githubusercontent.com/swedests/vkdart/master/articles/habr/images/12-incoming-message-event.png)

Не нужно отмечать все события подряд: включайте только те, которые программа действительно собирается обрабатывать. Так боту не придётся получать ненужные обновления.

10. В настройках сообщества откройте раздел **Сообщения** и разрешите пользователям писать сообществу. Затем в разделе **Настройки для бота** установите для **Возможностей ботов** значение **Включены**.

![Возможности ботов включены](https://raw.githubusercontent.com/swedests/vkdart/master/articles/habr/images/13-bot-capabilities.png)

Для справки: [как получать события сообщества через VK API](https://dev.vk.com/ru/api/community-events/getting-started).

Теперь сохраним ключ и числовой ID сообщества в отдельном файле. Это избавит нас от необходимости каждый раз вставлять длинный токен в основной код.

В VS Code найдите слева папку проекта `vk_bot`. Нажмите на неё правой кнопкой мыши и выберите **Создать файл** (или значок нового файла). Введите имя `config.dart` и нажмите `Enter`. Важно создать его в корне проекта — на одном уровне с `pubspec.yaml`, а не внутри `bin`. Можно скопировать [шаблон `config.dart` из исходников статьи](https://github.com/swedests/vkdart/blob/master/articles/habr/source/config.dart) и заменить значения своими.

Откройте новый файл и вставьте:

```dart
const String token = 'ВСТАВЬТЕ_СЮДА_КЛЮЧ_СООБЩЕСТВА';
const int groupId = 123456789;
```

Замените `ВСТАВЬТЕ_СЮДА_КЛЮЧ_СООБЩЕСТВА` на скопированный ключ, сохранив кавычки. Замените `123456789` на числовой ID именно вашего сообщества, но кавычки вокруг ID не добавляйте: в коде это целое число.

Числовой ID сообщества можно взять из адресной строки браузера на странице сообщества или его настроек. Например, в адресе вида `vk.ru/club123456/settings/bots` ID — это цифры после `club`; у некоторых сообществ вместо него используется префикс `public`. В `groupId` укажите только цифры, без префикса и остальной части адреса. На скриншоте несколько цифр закрыты для конфиденциальности.

![Числовой ID сообщества в адресной строке браузера; часть цифр скрыта](https://raw.githubusercontent.com/swedests/vkdart/master/articles/habr/images/14-group-id-url.png)

Файл с ключом не отправляйте другим людям и не прикладывайте к статье. Для учебы на своём компьютере такой вариант понятен и удобен. Если позже будете размещать бота на сервере, храните ключ в закрытых настройках сервера, а не в исходном коде.

## Пишем код бота ✍️

В проекте уже есть файл `bin/vk_bot.dart`. Найдите его слева в VS Code: нажмите на маленькую стрелку рядом с папкой `bin`, затем дважды щёлкните по `vk_bot.dart`. Вместо пошаговой сборки можно скопировать [полный исходный файл бота](https://github.com/swedests/vkdart/blob/master/articles/habr/source/bin/vk_bot.dart) в `bin/vk_bot.dart`.

В файле уже может находиться стартовый пример Dart. Выделите его содержимое и замените код частями. Так будет проще понять, за что отвечает каждый блок. После каждого шага сохраняйте файл сочетанием `Ctrl+S`. Пока не запускайте программу: сначала добавим все части. Если VS Code временно подчеркнёт незаконченный код, не пугайтесь — мы ещё не вставили все блоки.

### Часть 1. Подключаем пакет и создаём клиента

Сначала вставьте импорты и основу программы:

```dart
import 'package:vkdart/util.dart';
import 'package:vkdart/vkdart.dart';

import '../config.dart';

Future<void> main() async {
  final vk = VkDart(
    token,
    fetcher: Longpoll(groupId),
  );

  await vk.start();
  print('Бот запущен! Напишите ему в сообщения сообщества.');
}
```

`import` подключает нужные библиотеки. `config.dart` содержит наш токен и ID. Строка `Longpoll(groupId)` выбирает способ получения сообщений. Пока программа только запускает Long Poll, но ещё не отвечает — сейчас научим её слушать сообщения.

### Часть 2. Начинаем слушать входящие сообщения

Добавьте этот блок **после** создания переменной `vk` и **до** строки `await vk.start();`:

```dart
vk.onMessage().listen((event) async {
  if (!event.isInbox || !event.isNew || !event.isUser) return;

  final text = event.text.trim().toLowerCase();

  try {
    // Здесь будут наши команды.
  } on Exception catch (error) {
    print('Не удалось обработать сообщение: $error');
  }
});
```

Этот блок подписывает бота на поток сообщений. Проверка оставляет только новые сообщения в личном диалоге. `text` — текст сообщения без лишних пробелов по краям и в нижнем регистре: поэтому «Привет» и «ПРИВЕТ» для программы одинаковы.

`try` и `catch` нужны, чтобы показать ошибку, если при обработке сообщения что-то пойдёт не так. Пока внутри `try` стоит временная строка-комментарий; следующим шагом заменим её командами.

### Часть 3. Отвечаем на приветствие и команды

Замените строку `// Здесь будут наши команды.` на следующий код:

```dart
if (text == 'привет') {
  await event.replySendMessage(
    message: 'Привет! Я бот. Пока учусь, но уже рад знакомству 🙂',
  );
} else if (text == '/start' || text == '/help' || text == 'помощь') {
  await event.replySendMessage(
    message: 'Я умею здороваться и рассказывать о себе. '
        'Напишите /menu, чтобы открыть меню.',
  );
} else {
  await event.replySendMessage(
    message: 'Такой команды я пока не знаю. Напишите /help.',
  );
}
```

`if` проверяет условие, а `else if` — следующий вариант, если предыдущий не подошёл. Получается простой выбор: приветствие, справка или подсказка для неизвестной команды. `await event.replySendMessage(...)` отправляет ответ в тот же диалог.

### Часть 4. Добавляем клавиатуру

Теперь добавим меню. В блоке команд найдите последний `} else {` — тот, который отправляет ответ о неизвестной команде. Удалите всю эту ветку и замените её на следующий блок. В нём уже есть и меню, и прежний ответ для неизвестных команд:

```dart
} else if (text == '/menu') {
  final keyboard = VkDartKeyboard()
    ..addButtonText(
      'Помощь',
      color: VkDartKeyboardColor.primary,
    )
    ..addButtonText(
      'О боте',
      color: VkDartKeyboardColor.secondary,
    );

  await event.replySendMessage(
    message: 'Выберите кнопку. Сложного меню не будет 🙂',
    keyboard: keyboard,
  );
} else if (text == 'о боте') {
  await event.replySendMessage(
    message: 'Я написан на Dart с помощью библиотеки VKDart.',
  );
} else {
  await event.replySendMessage(
    message: 'Такой команды я пока не знаю. Напишите /help.',
  );
}
```

Теперь вся цепочка команд снова закрыта правильно: сначала приветствие, затем справка, меню, ответ «О боте» и в конце запасной ответ на незнакомый текст. Если редактор подчёркивает скобки, проверьте, что вы именно заменили старую ветку `else`, а не оставили обе.

У `VkDartKeyboard` есть готовые цвета и методы для добавления кнопок. Здесь мы используем обычные текстовые кнопки. При нажатии VK отправляет подпись кнопки как сообщение, поэтому бот обработает её тем же способом, что и текст, набранный вручную.

Нажмите `Ctrl+S`, чтобы сохранить файл. Наконец, `await vk.start()` запускает получение событий. Слово `await` просит программу дождаться запуска, а `async` в объявлении `main()` позволяет использовать `await`. Когда в терминале появится сообщение о старте, можно переходить к проверке ☕

## Запускаем и проверяем 🚀

Команды нужно выполнять в папке проекта `vk_bot` — той самой, где лежит `pubspec.yaml`. Если вы уже открыли папку в VS Code, выберите меню **Терминал → Создать терминал**. Внизу окна появится терминал.

Посмотрите на строку перед мигающим курсором. Если она заканчивается на `vk_bot`, всё хорошо. Если нет, перейдите в папку проекта командой `cd` и укажите путь к ней. Например, если проект лежит на рабочем столе:

```powershell
cd $HOME\Desktop\vk_bot
```

Сначала попросим Dart проверить и загрузить библиотеки проекта, затем запустим файл бота:

```powershell
dart pub get
dart run bin/vk_bot.dart
```

`dart pub get` скачивает зависимости, перечисленные в `pubspec.yaml`. Это нужно при первом запуске проекта или после изменения списка пакетов. `dart run bin/vk_bot.dart` запускает нашу программу.

Если всё настроено, в терминале появится сообщение «Бот запущен!». Не закрывайте терминал: пока он открыт, бот работает. Чтобы остановить программу, нажмите `Ctrl+C`. Если терминал вывел красную ошибку, не пугайтесь — прочитайте её сверху вниз и проверьте, на каком файле и строке он остановился. Ошибка часто указывает прямо на проблему.

Теперь откройте сообщество от собственного аккаунта и перейдите в личные сообщения сообщества. Проверьте бота по порядку:

1. Напишите слово «привет».
2. Напишите «помощь».
3. Напишите `/menu`.
4. Нажмите кнопку «О боте».

На «привет» и «помощь» бот отвечает обычным сообщением, `/menu` показывает клавиатуру, а нажатие «О боте» приводит к ответу о библиотеке. Кнопка «Помощь» тоже работает: VK отправляет её текст как обычное сообщение, поэтому срабатывает та же команда, что и при ручном вводе.

![Проверяем команду «помощь»](https://raw.githubusercontent.com/swedests/vkdart/master/articles/habr/images/16-chat-help.png)

Если бот не отвечает, спокойно проверьте настройки по списку:

1. В терминале запущена программа и видно сообщение **«Бот запущен!»**?
2. В `config.dart` указан токен именно этого сообщества, без пробелов до или после него?
3. `groupId` — числовой ID нужного сообщества, записанный без кавычек?
4. Разрешены ли сообщения сообществу и включены ли возможности ботов?
5. В настройках Long Poll включено событие `message_new`?
6. Вы тестируете в личных сообщениях сообщества, а не в комментариях или беседе?

Иногда причина — всего одна забытая галочка. Зато теперь у нас есть список, по которому её искать 🔎

## Что дальше

В примере мы использовали Long Poll, но VKDart поддерживает и Callback API через `Webhook`. Дальше можно добавить работу с вложениями, хранение состояния в базе данных, дополнительные команды или развернуть приложение на сервере. Примеры Long Poll и Callback API для VKDart 2.3.3 есть в [каталоге `example/` соответствующего тега](https://github.com/swedests/vkdart/tree/v2.3.3/example).

Когда базовый бот заработает, можно попробовать собрать его в исполняемый файл. Это необязательный шаг для первого запуска — обычной команды `dart run` достаточно. При сборке Dart создаст отдельный файл программы:

```shell
dart compile exe bin/vk_bot.dart -o bot
```

Запускайте получившийся файл на той же операционной системе и архитектуре, где его собрали. В этом учебном варианте токен встраивается в программу, поэтому не передавайте её посторонним. Для настоящего сервера ключ лучше хранить в защищённых настройках сервера.

На этом основа готова: бот принимает личные сообщения, здоровается, показывает клавиатуру и отвечает на команды. Он пока не умеет готовить кофе, но, возможно, это тема для следующей статьи ☕
